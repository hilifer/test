# 各岗位后台功能清单（草案，待确认）

> 参照《电商后台要求》的写法，按岗位整理。目标：每个岗位登录后看到**自己的工作台**，只看到自己需要的菜单，常用操作一步可达。
> 所有岗位通用：中英文界面一键切换、个人语言偏好、操作日志可追溯、手机端可用。
> 标记：✅ 已有　🔧 本批要做

## 〇、通用：岗位工作台框架

1. ✅ 登录后进入**岗位首页**：上方是本岗位的 3–6 个关键指标，中间是"今天要处理的事"（待办列表，点一下直达），下方是常用快捷入口。
2. ✅ 左侧菜单按岗位裁剪；一个人可以兼多个岗位（例如销售兼客服），菜单合并显示。
3. ✅ 待办提醒：右上角显示待办数；🔧 重要事件（新 A 级线索、客户等待回复、付款到账、物流异常、备份失败）推送企业微信，并可按人设置是否接收。
4. ✅ 权限细到功能开关（查看 / 编辑 / 删除 / 导出 / 审批），并可**按站点**分配（例如某人只管 YR GRID）。
5. ✅ 统一操作日志：谁、什么时间、对哪条数据、做了什么，可按人 / 模块 / 时间筛选和导出。
6. ✅ 账号停用、重置密码、离职一键回收（停用即踢下线）。

---

## 一、业务（销售）

**工作台指标**：今日新线索（A/B 级）、待跟进线索、本月报价额、本月成交额、待客户签署的合同、待收定金。

1. 线索
   - ✅ A/B/C/D 自动评级、评级依据、状态流转、生成报价。
   - 🔧 **线索分配**：按国家 / 品类 / 轮流自动分配给销售，可手动转交；每个销售默认只看自己的线索（主管看全部）。
   - 🔧 **跟进记录**：电话、邮件、WhatsApp 记录与下次跟进时间，到期提醒。
   - 🔧 公海：超过 N 天未跟进的线索回到公海，其他人可领取。
2. 报价与合同
   - ✅ PI 报价、AI 议价、审批、电子合同、签署后自动建订单。
   - 🔧 报价模板（常用条款、常用产品组合一键带入）。
   - 🔧 报价跟踪：客户是否打开过 PI / 合同链接、打开时间。
3. 客户
   - ✅ 客户档案、客户中心链接、历史订单。
   - 🔧 客户 360 视图：联系人、聊天记录、询价、报价、订单、售后、付款、评价集中在一页。
   - 🔧 客户分级与标签（经销商 / 工程商 / 终端，VIP），生日 / 节日提醒。
4. 🔧 销售业绩：个人和团队的线索转化率、报价→成交率、成交额、回款，按月对比和目标完成度。
5. ✅ 人工客服接管网站聊天。

## 二、运营（网站与营销）

**工作台指标**：今日访客、商品浏览、加购、下单转化率、在线成交额、待审核评价、待发布文章。

1. 商品运营
   - ✅ 上下架、排序、推荐、批量操作、AI 自动上架、新品 GEO 推广。
   - 🔧 **商品数据**：每个商品的浏览、加购、下单、转化率直接显示在商品列表里，可按数据排序，找出该优化的商品。
   - 🔧 首页与专区编排：推荐区、新品区、活动专区的商品和顺序。
2. 营销
   - ✅ 优惠券、评价审核、弃购提醒、经营看板。
   - 🔧 **推广活动**：建立活动（带 UTM 链接），统计访客、询价、订单、成交额；可录入投放花费，自动算 ROI、获客成本。
   - 🔧 限时折扣 / 满减活动（自动生效和结束）。
   - 🔧 邮件营销：按客户标签群发（只发给同意接收的客户），退订链接，打开率统计。
3. 内容与 GEO
   - ✅ 内容智能体写稿、审核发布、GEO 监测。
   - 🔧 关键词与排名记录、AI 搜索被提及率趋势图。
4. 🔧 数据导出 Excel（列名跟随语言）。

## 三、美工（素材与图片）——即《电商后台要求》，改为上架到独立站

1. ✅ 素材仓库：图片 / 视频 / 设计源文件，目录、标签、检索、版本与回滚、回收站、30G 容量与告警、水印、批量下载。
2. ✅ 商品链接拉取：粘贴供应商或参考网页链接，读取标题、图片和参数（竞品链接只读文案）。
3. ✅ 水印（预览 / 成品）；✅ 尺寸预设与批量改尺寸、一键多尺寸、白底、扩图、调色（含按参考图统一色调）、去噪锐化放大、涂抹局部修图；✅ AI 抠图 / 换背景（接 remove.bg 或兼容服务，配置 IMAGE_AI_KEY）。
4. 🔧 标题与提示词：AI 优化标题（指定语言和方向）、提示词模板库、版本记录。
5. ✅ 上架到独立站：选图放到主图第几张 / SKU 图 / 详情图，保存版本、一键回滚。
6. ✅ 上传前检查（尺寸、白底、比例）；🔧 品牌资产、排版模板、违禁词检查。
7. ✅ 任务中心：批量任务后台逐项处理，进度、每项结果、暂停 / 继续 / 取消、失败重试、日志；失败任务出现在工作台待办。

## 四、运维（系统与 IT）

**工作台指标**：两个站的在线状态、最近一次备份、磁盘 / 内存、今日错误数、外部服务状态。

1. 系统状态
   - ✅ 版本、运行时间、数据库与磁盘、后台任务记录、已执行的数据库迁移。
   - 🔧 **服务连通性检查**：大模型、金蝶、Stripe、PayPal、17TRACK、邮件、企业微信，一键测试，显示最近一次成功和失败。
   - 🔧 **错误日志**：服务器错误按时间列出（请求地址、错误信息、发生次数），可筛选和导出；新错误推送企业微信。
   - 🔧 两个站（北美 / 东南亚）在同一页查看状态。
2. 备份与恢复
   - ✅ 每日自动备份、恢复校验、轮换、异地复制、手动备份与下载。
   - 🔧 恢复演练记录；备份到期提醒。
3. 安全
   - ✅ 登录锁定、跨站防护、权限、操作日志（部分）。
   - 🔧 **登录记录**：每个账号的登录时间、IP、失败次数，异常登录提醒；查看和强制下线当前在线会话。
   - 🔧 密钥与配置检查：哪些环境变量未配置、哪些即将过期（如支付密钥、证书）。
4. 发布与版本
   - ✅ 网站构建记录、原子切换。
   - 🔧 网站版本列表（最近 3 个），一键回滚到上一版网站。
5. 🔧 定时任务一览：内容写作、GEO 监测、库存同步、物流同步、备份、弃购提醒，查看下次运行时间，可手动立即运行或暂停。

## 五、财务

**工作台指标**：待收定金、待收尾款、今日到账、待退款、待审批议价、本月回款。

1. ✅ 登记收款、退款（原路 / 线下）、议价授权政策与底价、议价审批。
2. 🔧 **应收账款**：按客户 / 账龄（30 / 60 / 90 天）列出，逾期提醒。
3. 🔧 **对账**：Stripe / PayPal 到账与订单逐笔核对，差异列表。
4. 🔧 发票：形式发票（已有）+ 商业发票（Commercial Invoice）和装箱单导出 PDF。
5. 🔧 财务报表：按月收入、退款、优惠、运费；导出 Excel；与金蝶收款单同步。

## 六、仓库 / 物流

**工作台指标**：待发货订单、今日已发、在途、物流异常、低库存、待处理补发。

1. ✅ 发货单（分批发货）、装箱计算、17TRACK 轨迹、售后补发、库存与金蝶同步。
2. 🔧 **拣货单 / 装箱单打印**：按订单或按批次打印，含 SKU、数量、箱号。
3. 🔧 批量发货：一次为多个订单录入运单号（可导入 Excel）。
4. 🔧 库存预警设置（每个 SKU 的安全库存）、入库 / 出库记录。
5. 🔧 运费模板（已有）+ 物流商对比（时效、费用）。

## 七、客服（售前售后）

**工作台指标**：等待回复的对话、今日对话数、平均首次响应时间、未结售后单、待审核评价。

1. ✅ 人工接管网站聊天、AI 自动答复、售后单处理、订单查询。
2. 🔧 **快捷回复**：常用回答模板（中英文），一键插入。
3. 🔧 **统一收件箱**：网站聊天、邮件（以及以后的 WhatsApp）在一个列表处理。
4. 🔧 客服绩效：响应时间、解决率、客户评分（对话结束后请客户打分）。
5. 🔧 知识库：常见问题维护，AI 回答时优先使用。

## 八、管理员 / 老板

**工作台指标**：两站总成交额、本月目标完成度、各岗位待办积压、系统健康。

1. ✅ 账号与权限、系统设置、所有数据查看。
2. 🔧 **全局看板**：销售、运营、财务、物流、客服关键指标一页看全，两个站可切换或合并。
3. ✅ 岗位与权限模板：新建岗位、勾选功能开关，保存为模板复用。
4. 🔧 审批流配置：哪些操作需要审批（大额折扣、退款、删除商品），由谁审批。

---

### 建议的开发顺序

1. 通用框架（岗位首页、菜单裁剪、功能级与站点级权限、统一操作日志）——所有岗位都依赖它。
2. 美工（素材仓库 → 图片处理 → 上架到独立站），即之前确认的《电商后台要求》。
3. 运维、业务、运营。
4. 财务、仓库、客服、管理员看板。
