# 数据字典：销售 → 交付闭环

本文件由 `node scripts/gen-dictionary-doc.mjs` 根据 `shared/dictionary.js` 自动生成。系统所有状态、允许的流转、编号规则都以此为准；后台、客户中心、AI 客服和金蝶对接读的都是同一份定义。

## 主线

线索 → 报价单（PI）→ 客户在线确认 → 订单 → 收定金 → 生产/备货 → 待发货 → 发货单（物流动态）→ 签收 → 完成；签收后可发起售后单（RMA），补发走售后发货单。

## 自动规则

- 客户在门户确认 PI → 自动生成订单（待付定金），并按配置推送金蝶销售订单。
- 登记收款累计达到应收定金 → 订单自动进入「生产/备货中」。
- 发货单状态改为「运输中」→ 订单自动变为「已发货」；改为「已签收」→ 订单自动变为「已签收」。
- 订单标记「已完成」前必须收清全款。
- 付款条款为「30% 定金 70% 发货前」或「100% 预付」时，待发货阶段未收清尾款会在订单页醒目提示。
- 订单占用库存 = 待付定金、生产/备货中、待发货三个状态的订单数量。

## 运输方式

- `sea` 海运 / Sea freight
- `air` 空运 / Air freight
- `express` 快递 / Express
- `rail` 铁路 / Rail
- `truck` 陆运 / Truck
